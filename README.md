<!-- PowerShell Shortcut:
    Create Folder
        mkdir foldername
    Create New File
        ni filename
    Delete .exe File
        gci -r -fi *.exe | ri

    Alias Breakdown for the Delete Command:
        gci: Get-ChildItem (Lists items in the directory)
        -r: -Recurse (Searches through all subfolders)
        -fi: -Filter (Targets specifically .exe files)
        |: Pipe (Passes the found files to the next command)
        ri: Remove-Item (Deletes the items passed to it) -->
